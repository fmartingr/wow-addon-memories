What the actions do

  • Revoke key stops every signed request of the key and deletes every character of the key, with its files and screenshots. Each character page then gives a 404. If the deletion fails part way, the key stays revoked: use Revoke key again to finish.
  • An open key registered without an invite code. It cannot upload screenshots, and the Settings page sets its data limit.
  • Save limits sets the storage limits of the key, in MiB. 0 is the default limit: the Data per open key setting for an open key, else MEMORIES_MAX_DATA_BYTES_PER_KEY and MEMORIES_MAX_SHOT_BYTES_PER_KEY. When the key holds more than a new limit, the stored data stays, and the server refuses each upload that would leave the key over the limit.
  • Approve screenshots lets the key upload screenshots with no request from the app. It shows for a key that is not revoked, not open and not approved.
  • Revoke screenshots denies screenshots for the key, deletes the image files and removes the screenshot links from its characters.
