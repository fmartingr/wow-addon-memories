What the actions do

  • Revoke key stops every signed request of the key and deletes every character of the key, with its files and screenshots. Each character page then gives a 404. If the deletion fails part way, the key stays revoked: use Revoke key again to finish.
  • Revoke screenshots denies screenshots for the key, deletes the image files and removes the screenshot links from its characters.
