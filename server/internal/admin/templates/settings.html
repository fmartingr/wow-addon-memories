Settings

Open registration

With open registration, the app registers a key with no invite code. An open key cannot upload screenshots, and it holds at most the data below. A key with an invite code keeps the normal limits.

The data disk has {{.Settings.FreePercent}} free space.{{if .Settings.Low}} This is at the limit or below it, so open registration is off.{{end}}

What the settings do

  • Open registration lets a new key register with no invite code. When it is off, a new key needs an invite code. A key that registered before keeps working in both cases, and so does its data.
  • Data per open key is the most journey data that one open key can store. It replaces MEMORIES_MAX_DATA_BYTES_PER_KEY, which applies to keys with an invite code. An upload past it gets 507.
  • Close open registration: the server checks the free space of the data disk once a minute. When it is at this percent or less, the server turns open registration off. It stays off until you turn it on here again. At 0, it closes only when the disk is full.
