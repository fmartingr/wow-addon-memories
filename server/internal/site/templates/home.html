What Memories records

Memories is a set of 6 addons. They write down what happens to each character: sessions, travel, deaths, progress, kills, gathering, loot, money, skills, groups and PvP. The data stays in the game's saved files on your computer until you choose to upload it.

The core addon, Memories, is always needed. You can turn each other addon off in the AddOn list to stop its recording.

What WoW Journey does

WoW Journey is the companion app for Windows, macOS and Linux. It reads the saved files and keeps a backup. It builds a journey for each character: a timeline, a map of the trail and your screenshots. It can also upload a character to this website, so that you can send the link to a friend.

How to start

Follow these steps in order. The addons come first, the app comes second.

  1. Install the addons

    Download the zip of the addons from the latest release. Unpack it into the Interface/AddOns folder of your game. The zip holds the 6 Memories folders. Start the game and turn on the addons in the AddOn list.

  3. Play

    Play your characters as you always do. Memories records the journey in the background. The game writes the saved file when you log out or type /reload.

  5. Install the WoW Journey app

    Download the app for your system from the same release. On the first start, a short wizard finds your WoW folder and sets a backup folder.

  7. Gather your journey

    The app reads the saved files and builds the journey of each character on your computer. It does this again each time the game saves.

  9. Connect to this website

    {{if .OpenRegistration}}

    Open the settings of the app and find the Website section. Press Register.

    {{else}}

    Ask the person who runs this website for an invite code. Open the settings of the app and find the Website section. Enter the code and press Register.

    {{end}}

  11. Upload and share

    Turn on the Upload switch, or press Upload now. The app shows a progress bar and then the link of each character. Press Copy link and send it to a friend.

A character page is unlisted: anybody with the link can open it, and nobody can find it on this site.
