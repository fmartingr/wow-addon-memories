# Fonts

Self-hosted fonts under the SIL Open Font License 1.1 (see `OFL.txt`).

- `Cinzel-Variable.woff2`: Cinzel, weight 400 to 900, from `Cinzel[wght].ttf`.
- `AlegreyaSans-400.woff2`, `-500.woff2`, `-700.woff2`: Alegreya Sans Regular, Medium and Bold.

Source: `github.com/google/fonts`, commit `5bb28733cec313b63fbd415b574b5ae35c8aa8b8`, folders `ofl/cinzel` and
`ofl/alegreyasans`. The TTF files were converted with `woff2_compress`.
