# Memories

<p align="center">
  <img src="assets/icon.png" alt="Memories icon" width="128">
</p>

**Memories** records the journey of each of your World of Warcraft characters for **WoW Forever**.

It writes down sessions, travel, deaths, progress, kills, gathering, loot, money, skills, groups, PvP and more.
The **WoW Journey** desktop app turns that record into a web page that you can share.

## Example

[Neral Brumamar (EU PvP)](https://wowjourney.xyz/forever/eu/brumamar/neral/#summary).
