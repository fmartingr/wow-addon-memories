# Fonts

The same fonts as the website (`web/fonts/`), as TTF files because Flutter does not load woff2. SIL Open Font License 1.1
(see `OFL.txt`).

- `Cinzel-Variable.ttf`: Cinzel, weight 400 to 900.
- `AlegreyaSans-400.ttf`, `-500.ttf`, `-700.ttf`: Alegreya Sans Regular, Medium and Bold.

Source: `github.com/google/fonts`, commit `5bb28733cec313b63fbd415b574b5ae35c8aa8b8`, folders `ofl/cinzel` and
`ofl/alegreyasans`.
