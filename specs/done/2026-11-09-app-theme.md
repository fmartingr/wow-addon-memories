# App theme: the website look in the desktop app, with top tabs

## Why

The website (landing page and character page) has a WoW-styled look. The desktop app used the Material default with a
brown seed. This change gives the app the same look and one shared source for the design values, with a check that
finds any difference.

## What

- **AC1 — Look:** the app is dark, with gold double-border panels, Cinzel capitals, Alegreya Sans text, and the gold and
  bronze buttons of the website.
- **AC2 — Tabs:** the main window has a header (crest and name) and the tabs Overview, Website and Settings at the top.
  The settings route is gone. A settings message shows above the tabs.
- **AC3 — Tokens:** `app/lib/src/theme/tokens.dart` is made from `web/base.css` and `web/lib/format.mjs` by
  `make app-theme`.
- **AC4 — Parity check:** `make theme-check` fails when the tokens, the fonts, a component value or the list of web
  components differ between the website and the app, or when a screen hard-codes a colour. CI runs it.
- **AC5 — Skill:** `.claude/skills/theme-parity` runs the check, fixes the differences and compares pictures of both
  (`make app-shots`, `scripts/theme-shot.mjs`).

## Decisions

| Decision | Reason |
|---|---|
| The website is the source of truth; the app copies it. | One place to change a colour. |
| Style Material widgets through `ThemeData`; add widgets only for the header, tabs, tags and panel title. | The screens keep their code and tests. |
| Dark only. | The website has one theme. |
| TTF copies of the fonts in `app/assets/fonts/`. | Flutter does not load woff2. |
| Component literals (gradients, shadows) stay in the Dart theme, listed in `docs/theme-parity.json`. | A CSS rule cannot become Dart by a script; the check compares the values. |
| `FilledButton.tonal` looks like `FilledButton`. | A Flutter button theme has one style. |
| The Website card and the registration are one tab; their "Open settings" button is gone. | Both are in the same tab now. |

## Out of scope

- A light theme.
- A new wizard layout (it takes the theme only).
- A gradient panel fill (Flutter `Card` has a flat colour).
